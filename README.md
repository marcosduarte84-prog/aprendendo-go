# Aprendendo Go (Golang)

Este repositório reúne meus exercícios práticos durante meus estudos de Go, com foco no desenvolvimento Back-end.

## Exercício: Usuários e maioridade

Neste exercício, pratiquei:

- Structs para representar usuários.
- Slices para armazenar uma lista de usuários.
- `for` e `range` para percorrer a lista.
- `if` para verificar a idade.
- Funções para mostrar e contar usuários.
- `return` para devolver o resultado de uma função.

## Objetivo

Aprender Go passo a passo e construir uma base para atuar como desenvolvedor Back-end Júnior.
